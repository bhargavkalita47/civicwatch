# Atlas style engine snapshot

This directory contains the original MIT-licensed Atlas Style Core sources from
`bhargavkalita47/Atlas`, commit `08533bdcc175a9a0dcb81919be19acf97175767b`.

The code is kept together to faithfully resolve the full Atlas theme export
(detail, advanced and semantic settings) without a CDN runtime dependency.
Do not edit its cartographic rules here. Update as a versioned group from Atlas.

CivicWatch integration lives one level up in `../atlasStyle.ts`.
